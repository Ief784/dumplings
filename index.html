服务器基本概况简介

  • 本服务器主要类型为Fabric模组服，生存养老，允许生存，建筑，红石生电，PVP
  • 服务器种子码为：5137322700759458547，可以用Chunk Base的Seed Map查询你想要的地形
  • 游戏版本为1.21.11
  • 模组加载器为Fabric
  • 游戏内有许多建筑，允许打卡拍照，如果有建筑改动的建议请联系建筑人，请勿擅自修改

如何进入服务器

在启动游戏后，点击多人游戏，然后点击添加服务器，第一栏服务器名称可改可不改，第二栏服务器IP：43.248.3.136:11451

在添加好服务器后，进入服务器可能会出现以下问题，解决方法见问题的下方（点击展开）：

  • 服务器未开启（无法连接至服务器） 请联系服主
  • 您不在白名单内（You are not whitelisted on this server） 请联系有白名单权限的管理员，将您的游戏ID添加到游戏白名单内（服主zkims，binsir，白瑶，Rainboism）
  • 错误的密码 请再次进入服务器，输入正确的密码
  • 无法连接至服务器（Connection refused:getsockopt） 服务器IP输错了，重新检查您输入服务器IP是否为正确IP
  • 客户端和服务器上安装的模组不一致 按照提示安装相应的模组

服务器常用指令

登陆用指令

  • /register 密码 确认密码
    使用当前ID和密码注册 
  • /l 密码
    登录，服务器有免密登录，登录一次后在一台电脑上一段时间内不需要重新登录

warp指令

  • /warp list
    查看所有公共传送点 
  • /warp set 传送点名称
    在该位置设置公共传送点 
  • /warp delete 传送点名称
    删除该公共传送点 
  • /warp tp 传送点名称
    传送到指定公共传送点

home指令

  • /home list
    查看自己所有设置的家 
  • /home set 家名称
    在您所处的位置位置设置家 
  • /home delete 家名称
    删除指定的家 
  • /home tp 家名称
    传送到指定的家

bal指令

  • /bal ID
    查看该玩家的金币数量，若未指定玩家默认查自己的

fly指令

  • /fly (ID) (true/false)
    开启/关闭飞行（一般来讲仅需/fly）

新手常见问题

若您认真阅读了上述内容并付诸实践，恭喜您，水平可以与多数玩家协作，以下内容可能会对您的游玩有所帮助

注：还是点击展开

  • 问：游戏版本是什么？我能用26.2吗？基岩版能进服务器吗？ 答：游戏版本为1.21.11，游戏版本低于1.21.11会导致游戏有大量物品无法正常显示，仅支持Java版
  • 问：离线能不能进服务器？ 答：支持正版，离线以及第三方服务器登录，但尽量使用皮肤站登录
  • 问：我用Forge或其他模组加载器可以吗？ 答：仅支持Fabric
  • 问：我能加模组吗？ 答：凡是未添加新物品的模组/辅助模组，服务器都兼容
  • 问：明明我是littleskin登录，为什么我进入服务器后我的皮肤没有显示？ 答：请添加万用皮肤补丁模组（CustomSkinLoader）
  • 问：服务器IP多少？ 答：43.248.3.136:11451
  • 问：服务器有传送点吗？ 答：具体传送点见QQ群公告
  • 问：既然是模组服那模组有哪些？ 答：群文件中的客户端中有辅助自制的整合包，也有模组列表，愿意自己折腾的可以自己调配
  • 问：FCL能进吗？ 答：若能装上模组列表里的模组应该能进，搜不到可以求助群友
  • 问：服务器有没有/rtp？ 答：目前没有
  • 问：在服务器该怎么获得金币(经济系统货币)？ 答：前往玩家商店出售或击杀生物，目前主城没有收购点
  • 问：投影mod该怎么使用？ 答：默认M键打开菜单，在官方客户端里M键会被世界地图覆盖，需要在按键控制中手动修改；把你的投影文件放到schematics文件夹内，然后点击加载原理图，选中对应的投影文件后即可加载，可以使用木棍调整投影位置，需要先手木棍然后用Ctrl+滚轮把模式调到2，这时点击地面可以移动投影，更详细的教程可以前往B站寻找
  • 问：为什么我用传送命令一直传送不了？ 答：可能有以下原因：传送倒计时期间受到伤害，传送倒计时未结束时使用新的传送命令，未知错误，服务器变成土豆了
  • 问：这份Q&A是服务器官方的吗？ 答：这份Q&A是玩家自己总结的，扩展了一些内容，有需要可以前往群文件寻找官方版本
